ProjectNov 2024

TruthLens AI

Deep learning fake news detection · Oct 2026

A system that reads a news headline and article and estimates whether it is real or fake. It fine-tunes DistilBERT in PyTorch and benchmarks it against a TF-IDF and Logistic Regression baseline on the WELFake dataset.

Built with

  • Python
  • PyTorch
  • DistilBERT
  • Hugging Face Transformers
  • Scikit-learn
  • Flask
  • HTML / CSS
  • Docker
  • Cleaned the data by removing duplicate, contradictory and very short articles, and agency-name shortcuts such as "(Reuters)".
  • Fine-tuned DistilBERT in PyTorch and trained a TF-IDF + Logistic Regression baseline to compare against.
  • Evaluated both models with accuracy, precision, recall, F1-score and confusion matrices.
  • Built a Flask web app and prediction API so anyone can paste an article and get a score.
  • Prepared the app for Docker deployment and examined its explainability and generalisation limits.

More code is on github.com/Gopikrish2k.
